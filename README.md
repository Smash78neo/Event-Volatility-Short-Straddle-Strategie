# Event-Volatility Short-Straddle-Strategie

Code und Daten zur Maturaarbeit von Neo Alexis Hauser (Kantonsschule Zug, 2026; Betreuung: Lukas Zehnder).

Die Arbeit untersucht, ob sich der Verkauf von ATM-Straddles auf SPY, QQQ und IWM vor US-Makromeldungen (2011–2025) systematisch lohnt, und prüft, ob ein Umfeldfilter und ein Gradient-Boosting-Modell die profitablen Ereignisse besser auswählen (Out-of-Sample ab 2018, inkl. Portfolio mit IBKR-Gebühren).

- **Arbeit:** `main.pdf`
- **Daten und Code:** [OneDrive](https://1drv.ms/f/c/a9e8ec2113463877/IgDriZbuOA8YTJx0GBaydNPpAaW984n9Wo_QlYEwifWkyz8?e=rLoSnI). Die Marktdaten unterliegen den Lizenzbedingungen der jeweiligen Anbieter (u. a. Cboe, FRED, LambdaClass).
